# Contributing to Mada.AI

Thanks for helping build an evidence-first research workspace.

## Principles

1. Evidence before prose.
2. Citations must support claims.
3. Provider adapters everywhere.
4. User-safe research traces only (no private chain-of-thought product feature).
5. Retrieved web content is untrusted data.

## Development

1. Install with `pnpm install`.
2. Copy `.env.example` to `.env`.
3. Prefer small vertical slices with tests.
4. Run `pnpm typecheck` and `pnpm test` before opening a PR.

## Pull requests

- Describe the user-visible behavior change.
- Include verification commands and results.
- Update docs/ADRs when architecture changes.
